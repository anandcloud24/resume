🛒 Google Store — E-Commerce Platform on AWS ⭐ Featured
A fully automated, end-to-end e-commerce shopping website inspired by the Google Store, built and deployed entirely on AWS. The project implements a complete DevOps lifecycle — from source code to production — with zero manual intervention. Infrastructure is provisioned as code using Terraform, the application is containerized with Docker and orchestrated by Kubernetes, deployments are automated via GitHub Actions CI/CD pipeline and managed GitOps-style with ArgoCD, and the entire stack is monitored through Grafana, Prometheus, and Kibana.
